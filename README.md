# Amazon-Sales-EDA-Project
End-to-end Exploratory Data Analysis on 250+ Amazon sales records  across 5 product categories using Python, Pandas, Matplotlib and  Seaborn to uncover revenue trends and business insights.

## Overview
Performed end-to-end EDA on 250+ Amazon sales records across 
5 product categories to uncover revenue trends and business insights.
